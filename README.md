## 🚀 PROJECT DESCRIPTION  
This **interactive 3D aquarium simulation** built with Three.js offers:  
✔ Immersive virtual aquarium environment  
✔ Realistic fish behaviors and animations  
✔ Complete aquarium maintenance controls  
✔ Dual viewing modes (first-person & third-person)  

---

## ✨ KEY FEATURES  

### 🐠 FISH ECOSYSTEM  
• **3 unique fish species** with distinct behaviors  
• **Dynamic hunger system** affecting movement  
• **Realistic swimming patterns** and animations  
• **Population control** (add/remove fish)  

### 🌊 AQUATIC ENVIRONMENT  
• **Interactive decorations** and accessories  
• **Dynamic water clarity system**  
• **Realistic lighting effects**  
• **Responsive design** for all devices  

### 🎮 INTERACTIVE CONTROLS  
• **Creative Mode**: Free camera movement  
• **Fish Mode**: First-person perspective  
• **Intuitive UI panel** for management  

### ⚙️ TECHNICAL HIGHLIGHTS  
• Built with **Three.js** (r128)  
• Custom **behavior algorithms**  
• Optimized **performance** with bounding boxes  
• **No dependencies** required  

---

## 🕹️ HOW TO USE  

### 🖱️ NAVIGATION CONTROLS  
◾ **T** - Third-person (creative) view  
◾ **F** - First-person (fish) view  
◾ **Mouse drag** - Rotate camera  
◾ **Scroll wheel** - Zoom in/out  

### 🛠️ AQUARIUM MANAGEMENT  
◾ **Fish menu**: Add/remove fish species  
◾ **Feed Fish**: Reset hunger levels  
◾ **Clean Aquarium**: Restore water clarity  

### ⏸️ PAUSE MENU (ESC)  
◾ Continue session  
◾ Return to main menu  
◾ View about page
